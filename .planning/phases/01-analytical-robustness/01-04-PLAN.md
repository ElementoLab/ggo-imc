Content:
```markdown
# Inter-Panel Consistency Analysis (ANA-07)

## Overview

The GGO-IMC study uses two complementary IMC panels:
- **PANEL_G** (tumor panel): 24 markers focused on epithelial, stromal, and T cell markers
- **PANEL_H** (immune panel): 28 markers focused on myeloid, lymphoid, and epithelial markers

## Shared Cell Types

The following broad cell types are identified in both panels:
- Epi.-like (PanCK+ in both)
- Fib. (aSMA+ in both)
- Endo. (CD31+ in both)
- Mac. (CD163+ in both, additional markers differ)
- CD4 T, CD8 T (CD3/CD4/CD8a in both)
- B (CD20 in both)
- NK (different marker combinations: CD56+CD57 in G, CD56+NKp44 in H)

## Consistency Assessment

### Design Rationale
The two panels were designed for complementary coverage, not redundancy. PANEL_G emphasizes the tumor-stroma interface (includes Vimentin, aSMA, ColI for stromal characterization and GranzymeB, checkpoint markers for T cell function), while PANEL_H emphasizes immune diversity (includes CD15, CD66b, CD117, VISTA for granulocyte/mast cell phenotyping and RAGE, SFTPC for epithelial subtyping).

### Quantitative Approach
For shared cell types identified in both panels, cell-type densities (cells per ROI area) were computed independently per panel. Concordance can be assessed by:
1. Spearman correlation of patient-level densities between panels for each shared cell type
2. Consistent group-level trends (e.g., G4 showing similar immune patterns in both panels)

### Patient-Level Analysis
The patient grouping (G1-G4) was derived from PANEL_G broad cell-type densities (14 cell types, hierarchical clustering on scaled PCA). PANEL_H immune analyses (myeloid polarization, cytokine expression) provide orthogonal validation of group-associated immune phenotypes without circular dependency.

### Limitations
- Panels were run on adjacent tissue sections, not identical cuts, introducing spatial sampling variation
- Cell-type identification uses different marker combinations per panel, so "Macrophage" in PANEL_G (CD163+, CD206+) vs PANEL_H (CD68+, CD163+) may capture slightly different populations
- NK cells use different marker panels (CD56+CD57 vs CD56+NKp44)

## Methods Text Suggestion (for Phase 3)
"Inter-panel consistency was assessed by comparing cell-type densities for shared populations (epithelial-like, fibroblast, endothelial, macrophage, CD4 T, CD8 T, B, NK) between the tumor-focused (PANEL_G) and immune-focused (PANEL_H) IMC panels. Patient grouping was derived exclusively from PANEL_G cell-type densities; PANEL_H analyses provided orthogonal immune characterization without circular dependency."
```
