Everything under `if __name__ == '__main__':` guard.

**Section 1 -- Compute IMC process-score centroids:**
- Load IMC AnnData (same pattern as patient_group.py)
- Compute process scores using EXACT same `processes` dict as patient_group.py (see interfaces above)
- Compute EMT score = Mesenchymal - Epithelial
- score_cols = ['EMT score', 'Epithelial score', 'Mesenchymal score', 'Fibrosis score', 'Angiogenesis score', 'B&T score', 'Pan-Immune score']
- Group labels: `adata.obs['Group'].str.replace('Group', '').astype(int)`
- Compute centroids: for each group g in 1..4, mean of score_cols for patients in that group
- centroid_matrix shape: (4, 7)

**Section 2 -- Compute Yoffe process scores:**
- Load Yoffe AnnData: `sc.read(metadata['yoffe_adata_path'])`
- IF Yoffe var.index contains cell-type names matching IMC: use same sc.tl.score_genes approach
- IF Yoffe uses different feature names: adapt the processes dict to match Yoffe's naming (user will clarify in Task 1)
- Compute same 7 scores + EMT score

**Section 3 -- Nearest centroid assignment:**
- `dists = cdist(yoffe_scores, centroid_matrix, metric='euclidean')`
- `yoffe_groups = np.argmin(dists, axis=1) + 1`  (1-indexed: G1..G4)
- Save assignments: `pd.DataFrame({'patient_id': yoffe_adata.obs.index, 'Assigned_Group': yoffe_groups}).to_csv('results/yoffe_group_assignments.csv', index=False)`

**Section 4 -- Enrichment test:**
- Cross-tabulate Assigned_Group vs Yoffe histology column (name from Task 1)
- If any expected cell count < 5, note it
- Use chi2_contingency for the overall test
- Compute G4 proportion in high-risk vs low-risk categories
- Write results to `results/yoffe_stratification_record.txt`:
```
# Yoffe et al. Cohort Stratification (ANA-01)

## Group Assignments
G1: {n} patients ({pct}%)
G2: {n} patients ({pct}%)
G3: {n} patients ({pct}%)
G4: {n} patients ({pct}%)

## Enrichment Test
Histology vs Group cross-tabulation:
{crosstab}

Chi-squared p-value: {pval}
G4 in high-risk: {n}/{total} ({pct}%)
G4 in low-risk: {n}/{total} ({pct}%)

Directional match with internal cohort: {yes/no assessment}
```
